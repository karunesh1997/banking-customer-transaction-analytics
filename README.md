# Banking Customer & Transaction Analytics

## Overview

An end-to-end banking analytics project using PySpark, Spark SQL,
Python and Power BI to analyze customer transaction behavior,
identify trends, segment customers and generate business insights.

## Business Objectives

- Analyze customer transaction behavior
- Identify high-value customers
- Analyze transaction trends
- Compare banking channels
- Analyze merchant categories
- Segment customers based on activity
- Identify unusual transaction behavior

## Technology Stack

- PySpark
- Spark SQL
- Python
- Pandas
- Power BI
- Jupyter Notebook

## Project Workflow

Raw Data
↓
PySpark Data Loading
↓
Data Quality & Cleaning
↓
Data Transformation
↓
Customer + Transaction Join
↓
Spark SQL Analysis
↓
Customer Segmentation
↓
Anomaly Detection
↓
Power BI Dashboard

## Key Analysis

### Customer Analytics
Analyzed customer transaction frequency, transaction value
and average transaction behavior.

### Channel Analytics
Compared transaction volume and value across UPI, ATM,
mobile banking, internet banking, branch and card channels.

### Merchant Analytics
Analyzed transaction patterns across merchant categories.

### Customer Segmentation
Segmented customers based on transaction activity.
